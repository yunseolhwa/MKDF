# 미니게임 자동화 스크립트 (Mini-Game Auto Bot)

이 스크립트는 화면에서 "초록색 바(목표 지점)"와 "커서(현재 위치)"를 인식하고, `Shift` 키를 제어하여 커서가 초록색 바 안에 머물도록 자동화하는 파이썬 봇입니다. (관성과 가속도가 있는 환경에 맞추어 PID 제어 방식을 사용합니다.)

## 필수 설치 항목

게임을 실행하는 PC(Windows 환경 권장)에 파이썬이 설치되어 있어야 합니다. 명령 프롬프트(cmd)나 터미널을 열고 아래 명령어를 입력하여 필요한 라이브러리를 설치해 주세요.

```bash
pip install opencv-python numpy mss pydirectinput
```

## 사용 방법

1. **캡처 영역 설정**:
   `mini_game_auto.py` 파일을 열어 `GAME_REGION` 변수를 수정해야 합니다.
   게임이 화면의 어디에 위치해 있는지에 따라 화면 캡처 영역을 지정해 주세요. 전체 화면 캡처보다 지정된 영역만 캡처하는 것이 속도가 훨씬 빠릅니다.
   ```python
   # 예: 화면의 (왼쪽 400, 위쪽 300) 위치에서 가로 800, 세로 200 크기만큼 캡처
   GAME_REGION = {"top": 300, "left": 400, "width": 800, "height": 200}
   ```

2. **스크립트 실행**:
   게임을 창 모드로 실행한 상태에서 스크립트를 실행합니다.
   ```bash
   python mini_game_auto.py
   ```

3. **GUI 튜닝 (중요)**:
   스크립트가 실행되면 `Mini-Game Bot`이라는 창이 뜹니다. 이 창에서 실시간으로 화면 인식과 봇의 행동을 미세 조정할 수 있습니다.

   * **HSV 슬라이더**: 화면에 표시되는 `Target Bar`(초록색 상자)가 게임의 진짜 초록색 바를 정확하게 감싸도록 `H_Min`, `H_Max`, `S_Min`, `S_Max`, `V_Min`, `V_Max` 슬라이더를 조절합니다.
   * **PID 제어 슬라이더**:
     * `Kp * 100` (비례 제어): 목표에서 멀어질수록 강하게 이동합니다. 너무 높으면 진동이 심해집니다.
     * `Kd * 100` (미분 제어): 목표에 가까워지거나 속도가 너무 빠를 때 브레이크 역할을 합니다. 관성이 클수록 이 값을 높여야 합니다.
   * **Bot Enabled**: 이 값을 `1`로 올리면 봇이 실제로 `Shift` 키를 누르기 시작합니다. 처음에는 `0`으로 두고 인식이 잘 되는지 확인한 뒤에 켜주세요.

4. **종료**:
   `Mini-Game Bot` 창이 활성화된 상태에서 키보드의 `q` 키를 누르면 안전하게 스크립트가 종료되고 `Shift` 키 눌림 상태가 해제됩니다.

## 팁 & 주의사항
* **커서 인식**: 현재 코드는 하얀색/밝은 회색의 캡슐 모양을 찾는 휴리스틱 방식을 사용하고 있습니다. 만약 게임 화면에서 커서 인식이 잘 안 된다면, `find_cursor` 함수 내의 `cv2.threshold` 값을 조정하거나 템플릿 매칭 방식을 활성화하여 사용해 보세요.
* 게임이 전체 화면인 경우 화면 캡처(`mss`)가 검은 화면으로 나올 수 있습니다. 반드시 "창 모드" 또는 "전체 창 모드(테두리 없음)"를 사용해 주세요.
* `pydirectinput`은 실제 키보드 입력 수준에서 작동하므로 게임 내에서 정상적으로 인식됩니다.
